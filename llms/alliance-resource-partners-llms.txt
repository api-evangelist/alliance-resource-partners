# Alliance Resource Partners, L.P.

> Alliance Resource Partners, L.P. (NASDAQ: ARLP) is a diversified energy and natural-resource partnership
> headquartered in Tulsa, Oklahoma: the largest coal producer in the eastern United States, plus an oil and
> gas mineral-royalty portfolio and a growth-investment arm. ARLP publishes no developer portal, no product
> API, no SDK and no API pricing. The only machine-readable interface it serves is the standard, read-only
> WordPress REST API behind its corporate site at www.arlp.com, which exposes ARLP's own corporate content
> (pages, media, taxonomy, search, blog posts) anonymously. This file was GENERATED by API Evangelist from
> the ARLP catalog entry and the artifacts in this repository; ARLP does not publish an llms.txt
> (https://www.arlp.com/llms.txt returns HTTP 404).

## APIs

- [Alliance Resource Partners Content API](https://www.arlp.com/wp-json): Read-only WordPress REST API over
  arlp.com corporate content. Anonymous, no key, no OAuth. 22 GET operations across pages, posts, media,
  taxonomy, comments, authors, search, discovery and oEmbed.
